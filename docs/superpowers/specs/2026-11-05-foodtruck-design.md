# BrandDNA 餐車版設計

使用者已授權在現有目錄直接改版，設計由實作者決定。品牌改用「新巨輪－海海人生行動餐車」，公開品牌介紹須有來源；價格、營業場次、會員與成效均清楚標示示範。

沿用 Pages、Workers、D1、R2 與舊版分析 API。新版使用獨立工作區資料，避免重置既有資料。舊版來源工具保留為進階入口。新版以暖白、墨綠、橘色構成商家工作台，手機點餐採同一視覺。

## 操作與完成條件

1. 商家總覽整合品牌、來源進度、成果、下一場擺攤與待確認貼文。
2. 資料中心可新增文字與檔案、補件、分析；診斷顯示 12 人格、依據、定位、語氣與客群。Demo 分析明示為示範規則，不冒充正式 AI 結果。
3. 依品牌生成 IG/FB 文案，自拍照上傳 R2、拍攝建議、字卡、可編輯預覽；修改後必須重新確認。
4. 確認才可模擬立即發布或未來排程；日曆同時顯示擺攤與貼文。
5. 示範成效能回饋至來源與診斷；市場模擬不出現在新版流程。
6. QR/測試入口開啟手機頁，模擬 LINE 綁定或訪客、示意會員資料、選餐、購物車、送單。D1 共用資料使另一裝置商家能接單並更新顧客狀態。
7. 規範守門員標為考慮移除，不是發布前置條件。

## 技術決策

保留原始範本/API，而非升級全新框架；減少部署變動。新版原生 ES modules 分拆 client、merchant、customer，後端獨立 truck 路由與 D1 版本文件。寫入比較 revision 並重試，避免同時點餐互相覆蓋。價格與訂單狀態由伺服器驗證，前端只提交品項與數量。

使用者於後續明確授權直接部署 Cloudflare；以獨立 foodtruck 專案與 D1 部署，保留舊版。帳戶未啟用 R2，故自拍照改用 D1 分塊保存，保留 R2 可選支援。不開啟真實 LINE/Meta/金流；正式會員欄位與集點待研究。方案選擇與付費額度不阻擋 Demo。現有目錄沒有 Git，依使用者指示原地修改。
